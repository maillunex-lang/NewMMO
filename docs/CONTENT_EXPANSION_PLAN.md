## 1. Диагноз (факты)

| Метрика | Значение |
|---------|----------|
| Секций MQ в `10_DIALOGUES.md` | **120 / 120** (все ID присутствуют) |
| Секций SQ | **120 / 120** |
| Типичный объём MQ-01-01…05 | **12** строк `DIA.*` на квест |
| Типичный объём SQ-01-001…005 | **13–15** строк |
| Клиентский runtime | только START/PROGRESS/TURNIN/DONE; OBJ-линии отсутствуют |

**Проблема не в отсутствии квестов**, а в **шаблонной генерации реплик**:

| Штамп | Вхождений в `10_DIALOGUES.md` |
|-------|-------------------------------:|
| «Я проверю это. Что требуется в первую очередь?» | 120 |
| «На бумаге всё выглядит просто» | 120 |
| «Доказательство важнее удобного объяснения» | 82 |
| «Дорога здесь изменилась, а протокол остался прежним» | 42 |

START.01 часто **вклеивает текст журнала** + штамп. OBJ — SYSTEM-подсказки, не живые сцены. Голоса Фейры / Ильры / Орина из `04_CHARACTERS.md` почти не различимы.

## 2. Цель этапа EX-CONTENT-01

1. **Не создавать** новые `MQ-*` / `SQ-*`. Сохранить ID, порядок, цели, награды, флаги из 08/09.  
2. **Переписать и расширить** `10_DIALOGUES.md` (и зеркальный runtime JSON после утверждения) до содержательных деревьев.  
3. Ориентиры объёма (содержательные реплики NPC/PLAYER, не считая сухие SYSTEM-хинты как «наполнение»):  
   - MQ: **12–25**  
   - SQ: **8–15**  
4. Обязательные стадии: **START, PROGRESS, OBJ1–OBJ3, TURNIN, DONE** (+ CHOICE где канон требует).  
5. Варианты ответа игрока в ключевых точках (`ACCEPT` / `ASK` / смысловые ветки без ломания графа).  
6. Тон: серьёзное фэнтези + институциональный сарказм; юмор не обесценивает жертв (`01`/`07`).  
7. Реплики **привязаны к состоянию** квеста и фактически выполненным целям.  
8. Формат ID: только **`DIA.*`** (C-DIA-001 A). Старые ID сохранять; новые индексы `.04`, `.05`… добавлять рядом.

## 4. Правила написания (чек-лист автора)

1. Сначала перечитать карточку квеста в 08/09 + бит в 07 + досье NPC в 04.  
2. START не копирует journal verbatim — даёт **сцену** и мотив.  
3. OBJ1–3: реакция **после** соответствующей цели (или hint **до**, но не путать); не выдавать DONE-знание раньше времени.  
4. PROGRESS: разный текст при 0/1/2 выполненных целях (минимум 2 варианта).  
5. TURNIN / DONE: итог сцены из 08 («сценарный итог»), без повторной выдачи награды в тексте.  
6. Игрок: ≥2 осмысленных варианта на START (принять / уточнить / сомнение); при choice-квестах — канонические A/B из 08/09.  
7. Запрет: новые квест-ID, новые обязательные цели, раскрытие тайны Договора до главы IV, массовый ренейм `DIA.*`.  
8. Можно добавить индексы (`START.04`, `PROGRESS.02`, `OBJ1.03`…) — не ломая существующие `.01`.

### 5.2 `MQ-01-02` — Два свидетеля (сжатый образец)

**Итог канона:** две независимые версии · улика `ITEM-Q-01-02`

- **START:** Фейра: «Один клянётся, что обоз ушёл на рассвете. Другой — что видел его в полдень на том же месте. Выбери не удобного, а противоречащего.»  
- **PLAYER:** «Опрошу обоих порознь.» / «Что если оба правы?» → Фейра: «Тогда мир ещё хуже, чем я думала. Всё равно — записи.»  
- **OBJ1 (Witness A):** живая реплика свидетеля (не именной канон-NPC → POI-голос): путаница дат, страх штрафа.  
- **OBJ2 (Witness B):** другая дата, другая уверенность; лёгкий сарказм про «бумагу, которая помнит лучше глаз».  
- **OBJ3:** стол улик — игрок **выбирает противоречащую запись** (не «обе истинны» в UI без канона).  
- **PROGRESS:** разный текст до/после одного свидетеля.  
- **DONE:** Фейра выдаёт тон «две правды — уже улика», без раскрытия Печати.

Целевой объём: 14–20 реплик.

### 5.3 `MQ-01-03` — След на дороге

**Контакт:** NPC-102 Ильра · explore · географическое противоречие
