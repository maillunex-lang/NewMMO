# T-006 — Обёртка HTTP-ответа для стриминга и upgrade

Проверено 2026-11-21. Middleware T-005 записывает итоговый HTTP-статус после возврата обработчика. Для будущего HTTP/1.x upgrade нужны прямые вызовы `http.Hijacker` и `http.Flusher`, а также те же операции через `http.ResponseController`. Каталог Hysen Labs использован для поиска httpsnoop, лицензия, активность и зависимости сверены с upstream. Выбор для T-006 — явные методы с делегированием через `ResponseController` и сохранением `Unwrap`. Успешный `Hijack` отмечаем в журнале как 101. Сырые байты пишет сам обработчик, поэтому статус в журнале обозначает успешную передачу соединения обработчику. Успешный flush фиксирует уже выставленный код или неявный 200. Legacy `http.Flusher.Flush()` не возвращает ошибку по своему контракту. Обработчик, которому нужна ошибка, использует контроллер. Для HTTP/2 Go намеренно не поддерживает `Hijack`. [Документация Go](https://pkg.go.dev/net/http@go1.25.0#Hijacker)
