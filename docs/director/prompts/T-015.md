## Что сделать
1. Работай в ветке `agent/client/T-015`. Сначала снять «до» на 4.3: `./tools/smoke_stage1.sh` (должен быть зелёным), эталонные кадры Dawn Valley/HUD/диалога/журнала (`client/scripts/dev/screenshot_stage1.gd` или эквивалент) — для сравнения.
2. Переключить проект на 4.7.2: открыть/реимпортировать (`--import`) бинарником 4.7.2, `config/features` в `project.godot` → ветка 4.7 (**GL Compatibility сохранить**, окно 1280×720 landscape, `canvas_items/expand` сохранить). Закоммитить **только объяснимые** изменения (UID-файлы `.gd.uid`/`.uid`, формат сцен, предупреждения скриптов); необъяснимые диффы сцен — разобрать и описать или откатить.
3. Исправить всё, что ломается/предупреждает на 4.7.2 (типизация GDScript, `CONFUSABLE_TEMPORARY_MODIFICATION`, Control/Theme, import translations `ui.csv`, плагин World Studio) — **минимально**, без изменений игровой логики и данных. Не использовать новые возможности 4.7 «для красоты».
4. Гейты на 4.7.2 (все должны быть зелёными и строгими): `./tools/smoke_stage1.sh` (import, boot, STAGE1, MQ01, NET маркеры), `python3 tools/content/check_client_sync.py`. Кадры «после» совпадают с «до» без необъяснимых отличий (слои, текст, HUD, safe-area, журнал); приложи оба набора или опиши сравнение.
5. **Android на 4.7.2:** обновить `tools/android/build_debug_apk.sh` (версия build-tools, пути, шаблоны), собрать debug APK бинарником 4.7.2, проверить `apksigner`, package, ABI, **minSdk/targetSdk из манифеста**, размер, JSON внутри; зафиксировать «до/после» с 4.3 (размер, SDK-уровни). World Studio: dock, размещение с undo/redo — проверить вручную в редакторе 4.7.2 и описать.
6. Отчёт обязан содержать: точные версии/SHA установленного, список изменённых файлов с объяснением, список warnings «было → стало», **точные требования для CI** (версии/пакеты Android SDK, что нужно скачать), оценку остаточных рисков и **план отката** (как вернуться на 4.3).
