## Правила, по которым проверяешь
1. Экраны — редактируемые `.tscn` Control-сцены + Theme-ресурсы; скрипты только привязывают данные и **не строят раскладку кодом**.
2. Landscape, учёт safe-area (вырезы/жесты Android), якоря/контейнеры вместо абсолютных координат; touch-цели не меньше ~48 dp (обосновать числом).
3. Нет захардкоженных игровых строк канона в GDScript; тексты диалогов приходят из данных (`client/data/dialogues`), UI-подписи — вынесены в Theme/сцену/ключи.
4. Клиент не авторитетен (ничего нового в обход сервера не добавляй).
5. Godot-версия остаётся 4.3 (C-GODOT-001 B): **не обновлять движок, не менять `project.godot` features**.
