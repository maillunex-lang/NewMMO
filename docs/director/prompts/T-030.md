# T-030 — Godot inventory bag UI (EX-P08)

**Lane:** client (+ director docs)  
**Depends:** T-029 ✔  
**Branch:** `cursor/ex-p08-inventory-ui-6dd6`

## Goal
Ship an editable `.tscn` inventory panel bound to server `scopes.inventory` / `inventory.delta`, with HUD open control and `inventory.move.request` on the net client. No third-party inventory addons (T-029 research).

## Acceptance
1. `client/scenes/ui/inventory.tscn` + `inventory_ui.gd` — bag / materials / quest_keys lists.
2. HUD Bag button + `main.tscn` instance; `game_world` binds net when online.
3. RU/EN strings in `ui.csv`.
4. `NetClient.request_inventory_move` + envelope allow-list.
5. FakeTransport smoke: snapshot → open panel → delta refresh → move outbound (`ONLINE_SMOKE_OK` / `NET_SMOKE_OK`).
6. Offline fallback reads local `player.inventory` when net unbound.

## Out of scope
Combat loot tables, equip slots, drag-drop UX polish (follow-up EX-P08).
