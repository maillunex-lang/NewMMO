## Цель
1. **Экран журнала квестов** — редактируемая сцена `client/scenes/ui/quest_journal.tscn` + скрипт, который только привязывает данные (раскладка в `.tscn`, не в коде; Theme-ресурс; landscape; safe-area через уже существующий `safe_area_margins.gd`). Показывает активный квест: название, журнал-текст, цели с прогрессом (n/m), награду; список завершённых. Кнопка открытия на HUD (≥48 dp), закрытие.
2. **Адаптер данных**: скрипт журнала получает данные только через небольшой интерфейс (например, методы/сигналы `QuestManager`: активные/завершённые квесты, прогресс целей) — чтобы позже его заменил серверный источник, без переписывания экрана. Не добавлять новую игровую логику, не менять награды/прогресс/флаги.
3. **Строки UI через `tr()`**: подписи интерфейса (AUTO, TALK, Далее, Закрыть, Принять, Спросить, Сдать, «Вы», заголовки журнала) вынести в файл переводов `client/translations/ui.csv` (ключи `ui.*`, колонки `keys,ru,en`), подключить в `project.godot` **только** секцией `[internationalization]` (locale/translations). **Игровой/канонический текст (диалоги, названия квестов, цели) в CSV не копировать** — он приходит из данных.
