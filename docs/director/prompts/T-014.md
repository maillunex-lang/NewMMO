## Что сделать (всё в одной ветке `agent/server/T-014`)
1. **I-01 — защита на уровне БД.** Новая миграция `server/migrations/00005_…sql` (не правь 00001–00004): в триггере `content_builds` при переходе `staged → published` **пересчитать `ingest_digest` и число сущностей из хранимых строк тем же SQL, что в контракте, и отклонить переход (SQLSTATE `55000`) при несовпадении**. Корректный `Down`. Тесты (**от имени `newmmo_content_publisher`, не только app**): прямой `UPDATE content_builds SET status='published'` для staged-билда с подменённым `payload` отклоняется; для нетронутого проходит только по допустимому пути; прямой сдвиг указателя на непроверенный билд отклоняется.
2. **I-03 — crossrefs.** В верификаторе бандла: `crossrefs.json` — строгий UTF-8 JSON-объект с ключами `schema`, `entities`, `unresolved`, `soft_group_ids` (в пределах лимитов размера); негативные тесты (не UTF-8, не объект, нет ключей, хеш верный, но содержимое мусор). Манифест **не** проверять на каноничность (контракт rev 1.2 это явно снимает): тест `TestVerifyHashesExactManifestBytes` остаётся, добавь комментарий со ссылкой на решение.
3. **I-05 — строгие роли.** Если задана переменная `NEWMMO_REQUIRE_ROLE_URLS=1`, интеграционные тесты **падают** (не откатываются к publisher), когда нет `NEWMMO_TEST_MIGRATE_DATABASE_URL` или `NEWMMO_TEST_APP_DATABASE_URL`; каждое соединение проверяется запросом `select current_user` и сверяется с ожидаемой ролью (`newmmo_content_publisher`, `newmmo_migrator`, `newmmo_app`). Локальный режим без переменной остаётся (мягкий).
4. **I-07 — golden-вектор.** Тест `ingest_digest` на малой фикстуре со строками, содержащими U+001E, U+001F, кириллицу и экранирование; ожидаемое значение — константа в тесте, **подтверждённая независимо** (воспроизведи формулу контракта отдельным кодом, например Python, для нормализованного `jsonb::text`; опиши метод в research-файле).
5. **I-11.** `Status`: читать синглтон `content_active` отдельным запросом и **падать с понятной ошибкой**, если строки нет.
6. **I-08.** Для best-effort audit при отказе БД — короткий дедлайн (≈2 с) и тест; поведение зафиксируй в README.
7. **I-06.** Одной строкой в `deploy/newmmo/README.md` и в doc-комментарии пакета: вход ограничен 64 MiB, декодированный набор сущностей держится в памяти целиком (бенчмарк пикового RSS отложен).
