## Что получилось и что нет
Линт `--proposal-dir … --strict` я прогнал: **0 ERROR** (стадии на месте, объём в коридоре, запрещённых штампов нет). Но он показал **33 предупреждения `DIA-EXACT`**: реплики `OBJ1.03`, `OBJ2.03`, `OBJ3.03` и `PROGRESS.01/.02/.03` у **шести разных квестов дословно совпадают между собой**. То есть вместо старых штампов появились новые, внутри пилота. Это возвращает ту самую проблему, ради которой пилот делается. Ты сам отметил, что прогресс «частично шаблонный». Это нужно исправить — не «позже», а сейчас.

## Что исправить (обязательно)
1. **Ни одна реплика NPC/PLAYER не повторяется дословно между квестами пилота** (и внутри квеста). `PROGRESS.01/.02/.03` и реакции `OBJn.03` — **уникальные для каждого квеста**, с конкретной деталью сцены: названием улики, столба, копии карты, подписи, брода, балки; голосом того, кто говорит. Пример плохого: «Теперь есть первый проверенный результат. Остальные ещё не подтверждены.» (годится для любого квеста). Пример направления хорошего: Фейра о конкретной уликах/мерках, Орин о конкретной зарубке/смете, Ильра о конкретном свидетеле/броде.
2. **Тон ближе к утверждённым образцам** (`CONTENT_EXPANSION_PLAN.md` §5.1 и §5.6): институциональный сарказм и характерный ритм NPC. Сейчас реплики аккуратные, но «ровные» и похожие друг на друга по интонации. Проверь на каждом квесте тест «закрой подпись — отличу ли я говорящего?».
3. **`LATER`:** добавить в каждый START осмысленный ответ игрока `LATER` (вежливая отсрочка, без принятия, без потери флагов) и ответ NPC на него. Отметь, как в плане §4 п.6.
4. **Пунктуация:** `DIA.SQ-01-005.DONE.01` без терминального знака — исправить.
5. **Минимум два варианта на PROGRESS остаются** (0 / 1–2 выполненных); для MQ-01-05 — три.
6. После правок прогони (если можешь) `python3 tools/content/dialogue_lint.py --proposal-dir docs/content/dialogue_expansion/pilot --strict`; цель: **0 ERROR и 0 WARN `DIA-EXACT` внутри пилота** (`DIA-PUNCT` тоже ноль). Если не можешь запустить — подсчитай вручную совпадения между квестами пилота и напиши, как проверял; директор прогонит сам.

## Ответы директора на твои вопросы (можешь опираться на них)
- **MQ-01-05, передача заключения Ильре:** цель OBJ-01-05-3 по канону — разговор с NPC-102 (`npc_interact`). Значит **Ильра может говорить** в реакции `OBJ3`, коротко (это не новая сцена, а сама цель). Квест принимает и сдаёт Фейра.
- **SQ-01-001:** NPC-801 в карточке — «Участник»: **можно дать ему 1–2 короткие реплики** (например, на журнал в OBJ3), без нового NPC-ID.
- **SQ-01-002:** варианты A/B и флага `SQC` **нет и не будет** — это квест категории `chain`, не `choice`. Цель `SQO-01-002-03` «выбрать, какую копию приложить к отчёту» — выбор **без последствий в состоянии**: любой вариант засчитывает цель; реплики могут по-разному её комментировать, но **не** создавать ветки/флаги. Существующие ключи `CHOICE.01` / `CHOICE.PLAYER` сохраняй как есть (линт их принимает). Убери из README пометку «блокирует интеграцию».
- **SQ-01-003:** писарь без NPC-ID — озвучивай через участников карточки (**NPC-101 Марвен Таль** — «Участник», и NPC-102 — контакт) или как реплику игрока, пересказывающего показания; нового говорящего не создавай.
- **SQ-01-004:** **NPC-903** — «Участник»: может говорить в сценах сопровождения, коротко, страхом, а не шуткой.
- **SQ-01-005:** триггер «проверки моста» = цель по карточке; NPC-903 в карточке не указан — не вводи его туда без необходимости.
- **`objectives_done`:** да, это **число полностью выполненных целей** (0/1/2); для целей с количеством (например «найти 2 группы») частичный прогресс внутри цели в предикатах не используется.
- **Реакции после цели:** это отображение/диалог, не прогресс. Если стадия после подтверждения сразу меняется, реакция показывается при следующем открытии диалога — допустимо.
