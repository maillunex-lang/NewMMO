## Что написать
Шесть файлов-предложений, по одному на квест, в формате «drop-in секция» — **буква в букву формат секции из `10_DIALOGUES.md`**, чтобы я мог механически подложить её вместо канонической и прогнать линт:
`docs/content/dialogue_expansion/pilot/MQ-01-05.dialogue.md`, `SQ-01-001.dialogue.md`, `SQ-01-002.dialogue.md`, `SQ-01-003.dialogue.md`, `SQ-01-004.dialogue.md`, `SQ-01-005.dialogue.md`.

Каждый файл начинается строкой `### \`QUEST-ID\` — Название` (название из канона), затем строка «**Место:** … **Контакт:** … **Условие показа:** …» как в каноне, затем реплики в формате
`- \`DIA.<QUEST>.<STAGE>.<NN>\` · \`SPEAKER\`: «текст» (\`ACTION\`/условие/пометка)`.
Правила:
- **ID:** существующие ключи (`.01`, `.02`, …) сохранить (их текст можно переписать), новые индексы добавлять рядом (`START.04`, `PROGRESS.02`, `OBJ1.03`…). Никаких `DLG-*`. Спикеры: `NPC-NNN` (только NPC из карточки квеста/04), `PLAYER`, `SYSTEM`. Эпизодических безымянных персонажей (свидетелей, писаря) озвучивать **через ближайший канонический NPC или как «голос на месте» без нового ID** — новые NPC-ID не создавать.
- **Стадии обязательны:** START, OBJ1, OBJ2, OBJ3, PROGRESS (**минимум 2 разных варианта**: 0 целей / 1–2 цели; для MQ-01-05 — три), TURNIN, DONE.
- **Объём содержательных реплик (NPC+PLAYER, SYSTEM-хинты не считаются):** MQ-01-05 — 16–24; SQ — 11–15.
- **START:** сцена и мотив, **не копия журнала**; игрок: минимум `ACCEPT` и `ASK` с разным смыслом (+`LATER`, если уместно); `ASK` возвращает в ту же сцену без смены состояния.
- **OBJ1–3:** подсказка (`SYSTEM`, короткая, содержит объект/условие) **до** цели; живая реакция **после** подтверждённого события; не выдавать знание, которого игрок ещё не получил.
- **PROGRESS:** разный текст в зависимости от числа выполненных целей, отметь условие в скобках (`ACTIVE && objectives_done==1` …).
- **TURNIN/DONE:** итог квеста по полю «сценарный итог»/«итог» в 08/09, **без повторного упоминания награды как действия** (награду выдаёт сервер); DONE даёт новую сюжетную перспективу/мост к следующему квесту.
- **Тон A** (утверждён), голоса по `04_CHARACTERS.md`; сарказм направлен на канцелярии и протоколы, не на пострадавших. **Запрещённые штампы** из руководства T-016 не использовать нигде. Не раскрывать тайну Договора; не вводить новых обязательных целей, наград, флагов, локаций.
- Длина: NPC ≤ 180 знаков, PLAYER ≤ 110, SYSTEM ≤ 140 (предупреждающие пороги линта); один смысловой поворот на реплику; терминальная пунктуация обязательна.
- Для выборов в SQ (поле `SQC` на карточке) — реализуй канонические варианты A/B из карточки, не придумывай свои; если на карточке выбора нет, `CHOICE` не добавляй.
