# T-006 — Server: Go 1.25 directive + WebSocket-ready response wrapper (stdlib only)

Ты — исполнитель **ChatGPT Codex (lane `server`)** проекта Lunex MMORPG. Писать можно только: `server/**`, `deploy/**` (в deploy ничего не нужно), плюс отчёт `docs/research/T-006-*.md`.

## Прочитай сначала
`AGENTS.md` → `docs/director/DIRECTOR.md` → `docs/research/T-005-go-service-baseline.md` → `server/internal/httpservice/` (код твоего T-005, уже влит в `main`) → `docs/ROADMAP_EXECUTION.md` (EX-P03, решения владельца: Go ≥ 1.25).

## Research-first (коротко, до правок)
Проверь по официальной документации Go, GitHub и каталогу Hysen Labs https://hysenlabs.com/projects, как принято оборачивать `http.ResponseWriter`, чтобы не ломать `http.Hijacker`, `http.Flusher` и `http.ResponseController` (нужно для будущих WebSocket-соединений, EX-P04/P05). Запиши ≥3 варианта (ручные интерфейсы-обёртки, `ResponseController`/`Unwrap`, готовые библиотеки вроде felixge/httpsnoop) с лицензией, активностью, зависимостями и выводом в `docs/research/T-006-response-writer.md`. **Реализуй только на stdlib; ничего не добавляй в `go.mod`.**

## Цель
1. Поднять директиву языка модуля с `go 1.22` до **`go 1.25.0`** (решение владельца: Go ≥ 1.25; CI уже использует 1.25.x). Больше ничего в `go.mod` не менять.
2. Сделать обёртку `statusWriter` совместимой с WebSocket: она должна давать `Hijack()` и `Flush()` (и работать с `http.NewResponseController`) без потери логирования статуса. Логирование для захваченного соединения: статус 101 один раз, без паники.

## Что сделать
- Правка только `server/go.mod` и `server/internal/httpservice/*` (+ тесты).
- Тесты (`httptest` + реальный `net.Listener`): `Hijack` через обёртку работает (сервер-хендлер захватывает соединение и пишет ответ 101-подобный/сырой); `Flush` работает для стрим-ответа; `ResponseController.Flush/Hijack` работают; существующие тесты не меняются по смыслу.
- `cd server && go vet ./... && go test ./... -race -count=1` зелёные на Go 1.25+ (если локально Go ниже — используй `GOTOOLCHAIN=auto`; если не скачивается, напиши об этом в отчёте, а не подменяй версию).
