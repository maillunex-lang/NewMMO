# Game content canon

Files in `docs/content/` are the **approved narrative and content canon** for Lunex MMORPG (story beats, character identities, geography, quest/NPC IDs, naming).

## Rules

- Agents and contributors must treat these documents as source of truth for lore and content IDs.
- Do **not** change plot, characters, geography, or IDs without explicit owner permission.
- If a needed canon document is missing, note the gap in research/implementation docs and use only already approved working titles from `docs/GDD.md` — do not invent new canon quietly.

## Status

Canon markdown files will be added here as story/world content is approved. Until then, use GDD working titles only for scaffolding (e.g. Dawn Valley, Asterville, Whispering Forest) and keep IDs provisional in code comments/data with clear `TODO(canon)` markers.
