# DAILY LOOP — ежедневный и недельный цикл (дизайн-предложение)

**Статус:** предложение директора, **не канон** (`docs/content/**` не менялся). Решения по параметрам делегированы владельцем 2026-11-21 («как больше нравится игрокам и удерживает»); нарратив (тексты заданий, диалоги) — новый канон, нужен отдельный «делай» владельца. Числа — стартовые гипотезы для настройки по телеметрии (как `PACING.md`).
**Цель:** при ограничении уровней по регионам (`PACING.md`) дать причину заходить каждый день, **не ломая темп 60 уровня за месяц** и без наказаний за пропуск.

## 1. Принципы (почему именно так)
1. **Дневной круг ≠ источник уровней.** Основная награда — жетоны фракций, материалы региона, косметика/титулы; опыт мал (≤ 4–5% до следующего уровня за день). Иначе игра превращается в обязаловку, а темп сюжета ломается.
2. **Короткий и завершаемый:** весь суточный круг 15–25 минут. «Закончил — свободен»: чувство завершённости удерживает лучше бесконечной гонки.
3. **Без наказаний (no-FOMO):** серия дней не обнуляется штрафом, есть «льготный день»; пропуск компенсирует канонический отдохнувший опыт. Ничего платного для пропуска/ускорения.
4. **Разнообразие по расписанию:** задания чередуются по чётности дня (две «смены»), события разнесены по времени суток, раз в неделю — крупная цель. Игрок не делает одно и то же дважды подряд.
5. **Только авторитетный сервер:** прогресс считается по событиям, которые видит сервер (убийства — серверный бой T-038c; взаимодействия/доставка — движок квестов; события — движок событий). Антиафк, один прогресс на действие (идемпотентность по `request_id`/ledger).
6. **Связь с миром:** задания принадлежат фракциям (`FAC-01…08`) и точкам региона; награды — репутация и косметика этих фракций. Дневная доска региона появляется, когда регион открыт.

## 2. Суточный сброс и время
Сброс **03:00 UTC** (канон `13_WORLD_EVENTS.md` §1, значение конфигурируется); активную попытку сброс не прерывает. Расписание показывается в локальном времени клиента. Индекс дня `D = floor((now_utc − 03:00) / 24h)`; чётность `D` выбирает «смену».

## 3. Доска дня региона (ежедневные задания)
Для каждого **открытого** региона и каждого дня выдаётся доска:
| Слот | Чётный день (смена «Патруль») | Нечётный день (смена «Поручения») | Награда |
|------|-------------------------------|-----------------------------------|---------|
| 1 | Охота: убить N врагов типа T региона | Разведка: обойти 3 точки интереса (POI) по маршруту | `FACTION_MARK` ×X |
| 2 | Трофей: добыть M материала с врагов региона | Доставка: передать предмет NPC фракции (по маршруту) | материалы региона |
| 3 | Элита дня: победить 1 элиту региона (одиночно или с друзьями) | Проверка: ответить на «запрос расследователя» (мини-цепочка из 2 шагов) | `FACTION_MARK` ×X + опыт |
| **Вызов дня** (необязательный) | на выбор из 2 усложнённых вариантов (ограничение: без лечения / за время / без получения урона от телеграфа) | то же | косметика/титул-фрагмент |
**Сундук дня** за все три обязательных: материал 2-го класса + шанс на косметический фрагмент (без экипировки с лучшими статами — не «пай-ту-вин» и не дисбаланс).
Шаблоны (`daily_template`): тип цели (`kill_type`, `collect`, `visit_poi`, `deliver`, `elite`, `chain`), параметры (враг/материал/POI/NPC из канона региона), числа по уровню региона (N растёт с уровнем), фракция-подавец, награда. Выбор шаблонов детерминирован: seed = `(регион, D)`; одинаковый для всех игроков региона в этот день (общий разговор «что сегодня»).
**Опыт:** `xp_daily = round(0.04 × XP_to_next(L))` на задание 3 и на сундук (≈ 4–8% за день суммарно); `rested XP` по канону PACING не отменяется.

## 4. События в течение игрового дня
Используем 18 канонических событий (`EVT-RR-001…003`). Каждый регион получает **4 окна в сутки** по 20–30 минут, разнесённых по времени суток, чтобы любой часовой пояс поймал хотя бы одно:
| Окно | Время (UTC) | Для МСК (UTC+3) | Роль |
|------|-------------|------------------|------|
| Утро | 06:00 | 09:00 | лёгкое событие, быстрое |
| День | 10:00 | 13:00 | основное событие региона |
| Вечер | 16:00 | 19:00 | групповое (больше участников, лучше награда) |
| Ночь | 19:00 | 22:00 | ночное/атмосферное (редкая косметика) |
Сдвиг ±N минут по региону и дню — детерминированный seed (канон: не запускать 18 событий одновременно). Событие: общий прогресс + **персональная награда один раз на экземпляр** (канон), вклад по полезным действиям, антиафк. Анонс за 10 минут (внутриигровой + опциональный push на Android, выключен по умолчанию).
**Раз в неделю** — мировой босс региона (канон: «1 раз/неделю»), награда 1 раз/неделю/персонаж.

## 5. Недельная цель — «Дорожная книга»
10 печатей за неделю: ежедневка = 1 печать, событие = 1 печать, подземелье (первое в неделю) = 2 печати, мировой босс = 2 печати; печати копятся из **любых** активностей — не требует ежедневной явки (мягко для тех, кто заходит реже). Награды: 3 печати — жетоны; 6 — материалы 2-го класса; 10 — недельный сундук (косметика/титул/материал высокого класса). Сброс по понедельникам 03:00 UTC.

## 6. Удержание без «тёмных паттернов»
- **Видимый прогресс:** ранги репутации фракций (жетоны тратятся на косметику, титулы, ремесленные чертежи региона) — долгосрочная цель, не зависящая от одного дня.
- **Возвращение:** отдохнувший опыт (канон) + «подарок возвращения» (материалы/сундук) после ≥ 3 дней отсутствия — без счётчика потерянных наград.
- **Серия** — только бонус (+10% жетонов на 7-й день), 1 льготный день в неделю; никакой потери прогресса.
- **Социальное:** события и вечернее окно групповые; «вызов дня» можно проходить вместе; шеринг прогресса не нужен.
- **Прозрачность:** на экране видно, что осталось сегодня, сколько минут займёт, когда следующее событие.

## 7. Экономика и защита баланса
- Жетоны персональные, не торгуются; стоки — косметика/титулы/чертежи; нет «жетонов за деньги».
- Награды экипировкой — только через подземелья/добычу (канон `11`), не через ежедневки.
- Потолок опыта от ежедневок в день (≤ 8% до следующего уровня), чтобы не обойти региональные ворота `min_level`.
- Все числа конфигурируются (`daily_config`), версионируются, метрики: доля завершивших дневной круг, среднее время, возврат D1/D7, отток по шагам.

## 9. Что решено мной (по делегированию) и что можно изменить
3 обязательных + 1 вызов; чётность дня как «две смены»; опыт ≈ 4% до следующего уровня на задание 3 и сундук; окна 06/10/16/19 UTC (удобно для МСК и соседних поясов — **поменять легко**, это конфиг); недельная книга из 10 печатей; серия без штрафов. Всё это — параметры, а не код: меняются без перекомпиляции после первых данных телеметрии.
